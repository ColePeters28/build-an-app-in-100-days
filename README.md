# Build an app in 100 days

I'm Kieran. I'm 15, I left high school, and I'm building a party app called Pull Up.
Every day for 100 days I post one step of building an app on Instagram ([@kieranveni](https://www.instagram.com/kieranveni/)), with Pull Up as the real example.
This repo is the written version: one short page per day that you can follow for your own app.

**Star this repo** (top right) so you can find it again. New pages land here as the videos go out.

## How to use this

1. Watch the day's video.
2. Open that day's page and do the "Your turn" part. It takes about 15 minutes.
3. Keep your answers in one note. Later lessons build on them.

You don't need to know how to code to start.
